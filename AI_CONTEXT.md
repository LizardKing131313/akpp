# AI_CONTEXT

Проект: AKPP
Цель: аккуратно скопировать akppcenter.com на Nuxt 4 + Directus. Без расширения скоупа и лишних итераций. Бюджет 90к, срок 2 недели.

Ключевой принцип
Делаем копию, а не улучшаем мир. Любая идея улучшения это отдельная задача, по умолчанию не делаем.

Стек
Nuxt 4
Vue 3
TypeScript максимально строго
Tailwind CSS, приоритет классы, кастомный CSS только если реально нельзя иначе
Directus + Postgres
IPX для изображений, много картинок, обязателен кеш
Nginx Proxy Manager, чужие проекты на сервере не трогаем
Только бесплатные технологии и open source
Пакетный менеджер только pnpm

Контуры
Два контура, dev и prod
Сейчас поднимаем dev без домена, доступ по IP:port
В будущем dev будет на dev поддомене
Контуры изолированы, отдельная папка, отдельное имя compose проекта, отдельные порты, отдельные volumes, отдельная БД
Чужой прод проект на сервере не трогаем никогда

Репозиторий и ветки
GitHub единственная репа
develop это dev
main это prod
Сборка выполняется на сервере
GitHub Actions делает только SSH, дальше git pull и docker compose build up
Никаких registry, никаких платных сервисов

SEO
Максимум из коробки Nuxt, SSR, meta, og, robots, sitemap, canonical
SEO поля храним в Directus и оттуда тянем
Dev всегда noindex
IPX и cache control обязательно

Качество кода, жестко и без компромиссов
TypeScript strict включен максимально
noUncheckedIndexedAccess включен
exactOptionalPropertyTypes включен
noImplicitOverride включен
useUnknownInCatchVariables включен
noEmit включен
Запрет any
Запрет неявных типов
Импорты строгие
Сортировка импортов обязательна
Prettier, одинарные кавычки, без ;, printWidth 100, trailingComma es5
Prettier плагин для Tailwind, классы сортируются
ESLint flat config, TypeScript ESLint, Vue plugin, import, perfectionist, unicorn, promise, node
Husky + lint staged, перед коммитом обязаны проходить eslint, prettier, tsc

Nuxt особенности
Допустимы автоимпорты Nuxt, линтер должен их понимать
Под pages и layouts возможны исключения чтобы не воевать с Nuxt
Приоритет читаемости и типобезопасности

Данные и страницы
Контент и страницы должны быть data driven из Directus
Города, услуги, марки и модели генерируются строго по шаблону
Заявки пока не критичны, но интерфейс закладываем

Правила генерации кода для ассистента в IDE
Перед тем как писать код, сначала коротко объясни что и зачем делаешь, человеческим языком, без канцелярита, без булшита
Я новичок в Nuxt и Vue, поэтому каждый важный шаг сопровождай короткой мотивацией, почему так и что будет если сделать иначе
Никогда не предлагай платные сервисы
Никогда не трогай чужие контейнеры и чужие проекты на сервере
Не расширяй скоуп, если задача не просит, делай минимум который закрывает цель
Если не хватает данных, скажи какие именно файлы или конфиги нужны, не выдумывай
Никогда не придумывай ссылки, только реальные проверяемые

Режим работы
Сначала план из 3-7 строк, потом код
Если правим инфраструктуру, сначала покажи что именно меняется, какие файлы и почему
Если правим типы или линтер, сначала объясни последствия, потом патч

Опасные места
Секьюрити не трогаем без явной задачи
Деплой схему не усложняем
Кеш IPX обязателен, но без экстремальной настройки пока не надо

Готовность к ревью
Любой код должен проходить tsc, eslint, prettier без ошибок
